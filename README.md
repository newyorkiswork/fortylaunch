# FortyLaunch

A web app I built around Google's Gemini API for FortyLaunch — an AI-assisted workflow tool. Originally scaffolded in [Google AI Studio](https://ai.studio/) and extended into a full Vite + React + Supabase stack.

> **Live:** [fortylaunch.vercel.app](https://fortylaunch.vercel.app)
> **AI Studio source:** [ai.studio/apps/drive/1lyYbv2NbJ5oNyL1izOLmmIPCiP2mDHHG](https://ai.studio/apps/drive/1lyYbv2NbJ5oNyL1izOLmmIPCiP2mDHHG)

## Stack

- **Frontend:** React 19 + TypeScript on Vite 6
- **Routing:** React Router v7
- **AI:** `@google/genai` (Gemini)
- **Data:** Supabase (Postgres + auth)
- **Charts:** Recharts
- **Icons:** Lucide

## Run locally

**Prerequisites:** Node.js 18+

```bash
git clone https://github.com/newyorkiswork/fortylaunch.git
cd fortylaunch
npm install
cp .env.example .env.local   # if no .env.example, create .env.local
# Add the following to .env.local:
#   GEMINI_API_KEY=...
#   VITE_SUPABASE_URL=...
#   VITE_SUPABASE_ANON_KEY=...
npm run dev
```

## Architecture notes

- Vite app entry at `index.tsx` → `App.tsx`
- Shared types in `types.ts`, app-wide constants in `constants.ts`
- Reusable components in `components/`, services in `lib/`
- The `metadata.json` is generated by AI Studio and kept for round-trip editing in the Studio app
